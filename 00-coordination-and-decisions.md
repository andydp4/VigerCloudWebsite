# Brief 00 — Coordination and Decisions

## Goal
Create the repository governance, decision log and integration plan before implementation begins.

## Work
- Create a private GitHub repository and protect `main`; use feature branches and reviewed pull requests.
- Record confirmed answers for: original brand assets/fonts, company/legal wording, VAT treatment, approved pages/copy, contact and privacy email destinations, CRM/email/booking/analytics providers, cookie approach and target domains.
- Define staging (`staging.vigercloud.com`) and production (`vigercloud.com`) only after checking existing DNS, mail records and live services.
- Maintain a decision log and a page/content inventory.

## Done when
- All unknowns are marked **confirmed**, **assumption**, or **blocked**.
- Every following brief has an owner, file boundary and test owner.
- No one is asked to invent legal copy, credentials, pricing entitlements or final logo files.
