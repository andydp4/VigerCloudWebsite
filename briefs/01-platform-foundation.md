# Brief 01 — Platform Foundation

## Goal
Create the shared Next.js/TypeScript application foundation that every later feature uses.

## Scope
- Set up Next.js, TypeScript, formatting, linting, tests, CI and environment-variable examples.
- Establish route layout, responsive shell, navigation, footer, error/404 pages and reusable UI primitives.
- Add token-based styling, font loading, image handling, metadata helpers, accessibility utilities and reduced-motion support.
- Set up strict environment validation, no-secret rules, security headers and basic error monitoring interfaces.

## Do not build
- Final corporate page content, Arcarna animation scenes, live payment, real email, CMS-specific screens or legal advice.

## Acceptance checks
- Fresh install/build/type check/lint/test commands succeed.
- Keyboard navigation, visible focus, skip link, responsive navigation and reduced-motion mode work.
- Core Web Vitals budget is documented and image/font loading is intentional.
- Staging and production configuration are separate; no secrets enter source control.
