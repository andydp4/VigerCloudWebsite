# Brief 06 — Compliance, SEO and Measurement

## Goal
Put legal surfaces, consent-aware measurement and search foundations into the application from the start.

## Scope
- Build templates for separate Viger Cloud/Arcarna privacy notices, cookies, terms, accessibility and security pages.
- Add metadata, canonical URLs, sitemap, robots, social images and appropriate structured data.
- Implement consent-aware analytics events for product views, scroll chapters, pricing, plans, forms, bookings, comparisons and video.
- Add redirects, error handling and no-index rules for staging/system pages.

## Acceptance checks
- Legal pages state placeholders where real data flows are not yet confirmed; they do not pretend to be final advice.
- Analytics does not run before the chosen consent rule allows it.
- Search and sharing previews are correct for every public route.
